# GramDrishti — Phase 8 Application Scope & Artifact Ingestion Contract

## Project Context
- **Project**: GramDrishti (Smart India Hackathon PS 26074)
- **Phase**: Phase 8 — Standalone Application & Presentation Layer
- **Pilot Region**: Coimbatore District, Tamil Nadu (180 Gram Panchayats, 8 Meteorological Observation Stations)

---

## 1. Absolute Protection of Previous Phases (Phases 1–7)

Phase 8 is strictly an **application and presentation layer**. It does NOT retrain models, alter metrics, recompute conformal intervals, modify schemas, or overwrite previous phase artifacts.

### Strict Boundaries & Read-Only Guarantees
1. **No Model Retraining**: No retraining of LightGBM residual models, logistic regression baselines, or quantile regression models.
2. **No Metric Alteration**: No alteration of Phase 4 ML metrics, Phase 5 uncertainty quantification (CQR) metrics, or Phase 6 rainfall evaluation metrics.
3. **No Artifact Overwriting**: All files in `models/`, `data/processed/`, `data/raw/`, `data/metadata/`, `configs/`, `src/`, and `docs/phase[1-7]*` remain untouched and strictly read-only.
4. **No Git Modifications**: No commits, resets, rebases, or pushes during or after execution.
5. **No Synthetic Fabrication**: Missing scientific outputs (such as data-limited or unobserved rainfall thresholds) will NEVER be replaced with fabricated zeros or synthetic placeholders.

## 3. Phase 7 Standalone & Absence Contract

Phase 7 (Reliability Engine & Agricultural Advisory) is being developed independently on another device.

### Handling Phase 7 Absences:
1. **Panchayat Reliability File (`data/processed/predictions/panchayat_reliability.csv`)**:
   - When absent, the application displays:
     > `Phase 7 reliability data is not available in this deployment.`
   - Continues displaying all available Phase 1–6 temperature, humidity, UQ, and rainfall data smoothly.
2. **Crop Advisory Engine**:
   - When absent, the application displays:
     > `Advisory engine data is not available in this deployment.`
   - No fake agricultural advisories or heuristic crop recommendations are invented.
3. **Freshness Tracking**:
   - If Phase 7 metadata is absent, the application derives freshness directly from dataset timestamps (`valid_time`, `observation_time`, file modification times).

## 4. Scientific Truths Preserved in Phase 8

1. **Pilot Scope**: Clearly identifies the pilot domain as **Coimbatore District, Tamil Nadu** (180 Gram Panchayats).
2. **Uncertainty Limitations**: Humidity UQ is marked with its known temporal shift limitation (summer distribution shift, low test coverage) rather than hiding it.
3. **Rainfall Evaluability**:
   - $\ge 1\text{ mm}$: Fully evaluated and calibrated.
   - $\ge 10\text{ mm}$: Clearly labeled as **Data-Limited** (insufficient historical extreme events in training).
   - $\ge 25\text{ mm}$: Clearly labeled as **Not Evaluable** (0 events observed across training/test periods).
   - `NOT_EVALUABLE` states are never converted into misleading 0% probabilities.
4. **Spatial Aggregation Limitations**: Panchayats with `SUBGRID_RANGE_UNRESOLVED` (e.g., `GP_33_12_0114`, `GP_33_12_0165`) have their boundary status prominently displayed.
